# Render MVP deployment

WebGenius uses one Render web service for the NestJS platform API and its small generated-backend preview processes. React preview artifacts remain on Cloudflare R2.

## Deploy

1. Push this repository to GitHub or GitLab.
2. In Render, choose **New > Blueprint** and select the repository.
3. Render reads the root `render.yaml` and creates the free `webgenius-api` service.
4. Enter every environment variable marked `sync: false` when Render prompts for it.
5. After deployment, verify `https://<service>.onrender.com/health` returns `{ "ok": true }`.

Do not put secrets directly into `render.yaml`.

## Required secrets

| Variable | Purpose |
| --- | --- |
| `MONGODB_URI` | MongoDB Atlas connection string |
| `V0_API_KEY` | React frontend generation |
| `ANTHROPIC_API_KEY` | Blueprint and Express backend generation |
| `CLAUDE_MODEL` | Claude model available to the Anthropic account |
| `FRONTEND_URL` | Allowed UI/R2 origins, comma-separated when there is more than one |
| `R2_ACCOUNT_ID` | Cloudflare account identifier |
| `R2_BUCKET` | Preview artifact bucket |
| `R2_ACCESS_KEY_ID` | R2 S3-compatible access key |
| `R2_SECRET_ACCESS_KEY` | R2 S3-compatible secret |
| `R2_PUBLIC_BASE_URL` | Public bucket or custom-domain base URL |

`JWT_SECRET` is generated by the Blueprint on first creation.

## Frontend configuration

Build the main WebGenius frontend with:

```env
VITE_API_URL=https://<service>.onrender.com
```

Generated React artifacts receive a project-specific API base during the R2 build. Calls are routed to:

```text
https://<service>.onrender.com/fullstack/runtime/<projectId>/api/*
```

## Free-tier behavior

- Render exposes only the NestJS `PORT`; generated Express processes use internal ports 4100–4101.
- A maximum of two generated backends can run concurrently.
- Generated processes stop after 15 minutes without API traffic.
- Runtime directories and `data.json` are ephemeral and can reset after sleep, restart, or deploy.
- Generated source and project configuration remain in MongoDB and can reconstruct the runtime workspace.
- This runner is intended for a controlled MVP. Generated processes do not provide production-grade tenant isolation.

## Render commands

The Blueprint configures:

```text
Root directory: backend
Build command: npm ci && npm run build
Start command: npm run start:prod
Health check: /health
```
